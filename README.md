# Review Lab · W6 screen previews

Static previews for GitHub Pages. No Node server or API key is needed on the host.

- **skeleton/**: starting UI, with an optional 20-review saved sample.
- **complete/**: 300 saved reviews, interactive table, explorer, charts and CSV export.

Collection settings are display-only. Neither preview contacts Steam. The original lab projects are unchanged. Only selected review data and frontend assets are included; collection implementation is not included.

## Publish

1. Upload the **contents** of this folder to the root of a GitHub repository.
2. Open **Settings → Pages → Deploy from a branch**.
3. Choose your branch (usually **main**) and **/(root)**, then Save.
4. Open the published URL shown by GitHub Pages. Append **/skeleton/** or **/complete/** to share each preview directly.

[GitHub Pages instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
